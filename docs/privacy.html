Magnify.Snap

Privacy Policy

Last updated: 6 August 2026

Short version: Magnify.Snap collects nothing about you. There is no telemetry, no analytics, no accounts and no advertising. The only network request the application can make is an optional check for a new version, which you can switch off.

Data the application collects

None. Magnify.Snap does not gather, store or transmit personal data, usage statistics, screen contents, keystrokes or any identifiers.

Data stored on your computer

Your settings — zoom level, hold-to-peek level, activation binding, panning speed, appearance and whether the update check is enabled — are stored locally in a plain JSON file:

  • Windows: %APPDATA%\MagnifySnap\config.json
  • Linux: ~/.config/magnifysnap/config.json

This file never leaves your computer. Deleting it resets the app to its defaults.

Network communication

When the “Check for updates daily” option is enabled (the default), the application makes one anonymous HTTPS request per day to the public GitHub API endpoint of its own repository, to learn the latest released version number:

  • https://api.github.com/repos/violet2code/magnify-snap/releases/latest

The request carries no account, no identifier and no information about you or your computer beyond what any HTTPS request unavoidably reveals to the server (your IP address and a generic user agent). GitHub processes such requests under its own privacy statement.

If you click the update button, the application additionally downloads the release file from GitHub and verifies its SHA-256 checksum. No other connection is ever made. Switching off “Check for updates daily” in the settings stops all network activity.

Website

This website is hosted on GitHub Pages. It sets no cookies and runs no advertising or tracking scripts. It records a single anonymous counter of page visits (a plain number, with no personal data, no cookies and no profiles) so the author can see whether anyone is using the project.

Children

The application is a general-purpose accessibility utility and is not directed at children. Since it collects no data, none is collected from anyone regardless of age.

Changes

If this policy ever changes, the updated version will be published on this page with a new date. The application is open source, so any change in its network behaviour is visible in the public source code and its commit history.

Contact

Questions or concerns: open an issue on GitHub.
